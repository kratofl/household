# Contributing Guidelines

Thank you for considering contributing to this project!

## Branch Naming

Please use the following conventions for branches:

- Features: `feature/name-of-feature`
- Enhancement `enhancement/name-of-enhancement`
- Bug: `bug/issue-id-description`
- Chore: `chore/name-of-chore`

## Issues

- Search for existing issues before creating a new one.
- Describe the problem clearly and precisely.
- Use descriptive titles.

## Pull Requests

- Fork the repository and create a branch using the conventions above.
- Write short but descriptive commit messages in English.
- Describe what you changed and why in the pull request.
- Reference relevant issues (e.g., `Relates #42`), if applicable.
- PRs will be reviewed before being merged.

## Code Style

- Write clear, readable, and documented code.
- Follow existing conventions and code standards.
- Run existing tests before submitting.

## Communication

- Be friendly and respectful.
- Feel free to ask questions if something is unclear.
